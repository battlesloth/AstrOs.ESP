# Implementation Plans (retired 2026-08-16)

This directory is retired for new work. The plan-file convention it described was replaced by the agentic task workflow — see the **Workflow** section of `CLAUDE.md` and the rationale in [`.docs/agentic-workflow.md`](../agentic-workflow.md).

- **New work** gets a task file in [`.docs/tasks/`](../tasks/) (`T-NNN-<slug>.md`, template at [`.docs/templates/task.md`](../templates/task.md)), tracked in root `PLAN.md`.
- **Historical plans** live in [`.docs/completed-plans/`](../completed-plans/), organized by month, as the durable record of what was done and why.
